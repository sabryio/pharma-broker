# PharmaBroker - Complete AI Design Prompts

A comprehensive collection of AI design prompts for every page of the PharmaBroker application. Copy each prompt directly to your AI design tool (Midjourney, DALL-E, Gemini, etc.).

---

## Design System Constants

**Include these in every prompt for consistency:**

```
Theme: Deep Night - premium dark mode
Backgrounds: Obsidian (#0B0E14), Slate (#161B22)
Style: Glassmorphism with backdrop-blur, 1px borders
Accents: Teal (#00F2FF) for offers, Amber (#FFB800) for requests, Emerald (#00E676) for success, Rose (#FF4757) for errors
Typography: Inter or Outfit sans-serif
End with: "No device frame. High resolution. Professional pharmaceutical tech aesthetic."
```
